# freeCodeCamp Advertising Market Analysis

This project analyzes the freeCodeCamp 2017 New Coders Survey to identify the best markets for advertising coding products. It uses R to explore coder locations, market density, and spending habits, providing actionable insights for an advertising strategy.

## Files
- `market_analysis.R`: R script containing the analysis and visualizations.
- `2017-fCC-New-Coders-Survey-Data.csv`: Dataset used for the analysis (if not included, download from [https://github.com/freeCodeCamp/2017-new-coder-survey/tree/master/clean-data]).


## How to Run
1. Install R and the required packages (`dplyr`, `ggplot2`).
2. Place the dataset in the project folder.
3. Run `market_analysis.R` in R or RStudio.
